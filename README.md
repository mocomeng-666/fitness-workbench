# 个人健身训练工作台

一个原生 HTML、CSS、JavaScript 编写的中文健身 PWA，支持 8 周训练计划、逐组记录和进展回顾。动作详情全部使用文字要领与常见错误说明。

## 功能

- 首次配置档案、每周 2–5 天排期、8 周力量与有氧计划。
- 练前状态建议、RIR 与双重进阶、膝部保护、休息计时、替换动作和加入今日训练。
- 训练趋势、身体测量、体态照片、周报分享卡、自定义署名、有氧选项和三种主题。
- JSON 记录导入导出、照片 ZIP 导出、离线应用外壳。
- 可选 AI 器械识别：自行配置服务商、模型与 API Key。

## 本地运行

需要 Python 3，无需安装前端构建依赖。

```sh
python3 build.py
python3 -m http.server 8000 --directory dist
```

打开 http://localhost:8000 。请通过 HTTP 服务访问，不要直接双击 HTML。首次在线加载并完成服务工作线程安装后，核心训练与文字动作库可离线使用；AI 识别仍需联网。

`src/` 是开发源码；`build.py` 按顺序内联样式和脚本，生成 `dist/index.html`，另保留 `sw.js` 与 `manifest.webmanifest`。每次构建会重新生成整个 `dist/`，不要手动在里面保存个人文件。

## GitHub 分享与部署

本仓库同时包含源码与可部署的 `dist/`。将本目录内容上传到你新建的 GitHub 仓库即可分享代码。部署网站时，将 `dist/` 内容发布到 GitHub Pages 或其他 HTTPS 静态托管服务。资源使用相对路径，支持仓库子路径。

修改源码后重新构建；发布新版本前更新 `src/sw.js` 的缓存版本。安装 PWA 的支持情况取决于浏览器。

## 数据与隐私

训练档案、记录、测量、体态照片及设置保存在当前站点的浏览器 IndexedDB，不会随源码上传。不同域名或浏览器之间不会自动同步；清除站点数据会丢失本地记录。

JSON 备份含档案、训练与测量记录，不含体态照片、设置或 API Key。照片需单独导出 ZIP。不要把真实备份、照片、密钥或部署账户缓存放入仓库。

AI 识别会把所选照片发送至用户配置的服务商，并使用所填 API Key 鉴权。Key 保存在本机浏览器中，未加密；不提供服务端代理。接口是否支持浏览器跨域请求、模型是否可用及调用费用由服务商决定。无需配置 AI 也能使用其他功能。

训练内容是建议，不构成医疗诊断或治疗方案。

## 项目文件

- `src/data.js`：动作、计划和页面文案。
- `src/app.js`：页面、交互、照片、分享卡与可选识别。
- `src/engine.js`：训练建议与进阶计算。
- `src/db.js`：本地存储及导入导出。
- `src/index.html`、`src/styles.css`：页面结构与样式。
- `src/sw.js`、`src/manifest.webmanifest`：离线缓存与安装配置。
- `SPEC.md`、`REPROMPT.md`、`REPROMPT_full.md`、`docs/PRD_v2.0_source.md`：已脱敏的规格及历史说明，部分历史描述已被后续版本取代。
